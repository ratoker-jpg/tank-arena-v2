# Tank Arena V2

Публичный форк проекта [ganson-labs/tank-arena](https://github.com/ganson-labs/tank-arena) под аккаунтом `ratoker-jpg`. Исходный репозиторий и аккаунт автора не изменялись. Ветка `main` этой версии включает локально перенесённые изменения: управление танком человеком, выбор одной карты на матч/турнир и `--fresh` для песочницы.

Атрибуция исходному проекту сохранена; отдельная лицензия в этой версии не добавляется.

Это турнир один на один между танками, которых создают нейросети: имя, девиз, внешний вид, характеристики и искусственный интеллект. Зависимостей нет, нужен только Node.js 18+.

Если модель имеет доступ ко всему репозиторию, дай ей [`prompts/create-new-tank.md`](prompts/create-new-tank.md). Для более простой модели, которой разрешено изучить предыдущие танки и стенды Опуса и Астры, есть [`prompts/create-new-tank-with-examples.md`](prompts/create-new-tank-with-examples.md). Оба промпта просят создать участника в отдельной папке и не менять `main`. Если модель уже запущена внутри подготовленной папки участника, используй [`prompts/tank-battle.md`](prompts/tank-battle.md).

На Windows можно запустить [`Launch Tank Arena V2.ps1`](Launch%20Tank%20Arena%20V2.ps1) или ярлык `Запустить Tank Arena V2`; он использует порт 4748, чтобы не конфликтовать с другой локальной копией. Нужен Node.js 18+.

## Как провести бой

1. Создай папку каждому участнику. Это копия `kit/` с отдельным git, чтобы модели работали независимо друг от друга.

   ```
   node new-contestant.mjs opus  --model "Claude Opus 5.5" --color "#e8825a"
   node new-contestant.mjs astra --model "GPT-6 Astra"     --color "#4fc3c9"
   ```

2. Запусти агента в его папке (`contestants/opus` — Claude Code, `contestants/astra` — Codex) и дай промпт из [prompts/tank-battle.md](prompts/tank-battle.md), одинаковый для обоих. Для модели с доступом к корню репозитория используй [prompts/create-new-tank.md](prompts/create-new-tank.md).

3. Когда оба закончат, запусти просмотрщик и открой http://localhost:4747:

   ```
   node serve.mjs
   ```

   «Представление и бой» показывает карточки танков, затем матч до нужного числа побед. После матча `T` запускает турнир на скорости (по умолчанию 100 раундов), статистика по картам — в конце.

Быстрый старт по ссылке: `http://localhost:4747/?a=contestants/opus&b=contestants/astra&first=4&auto=intro`.

Поле «Карта» в меню фиксирует одну карту на весь матч или турнир (стороны при этом по-прежнему чередуются каждый раунд); по умолчанию карты идут по кругу. В ссылке — `map=Каньон` или `map=3`.

Клавиши: пробел — старт/пауза, `1`/`2`/`3`/`0` — скорость ×1/×2/×4/×0.5, `M` — звук, `F` — полный экран, `D` — ошибки и пропуски ботов, `Esc` — меню.

## Сыграть самому

В списке участников есть «Человек» — танк без бота, которым управляешь ты. При его выборе в меню появляются четыре поля характеристик: те же 10 очков, что у ботов (в ссылке — `hs=0,0,5,5`). Управление: `W`/`S` или `↑`/`↓` — газ, `A`/`D` или `←`/`→` — поворот корпуса, мышь — башня, левая кнопка или пробел — огонь, `Q`/`E` — башня без мыши, `P` — пауза. Бот напротив не знает, что играет с человеком, и видит тебя так же, как любого соперника. Турнир на скорости с человеком не запускается. Против Манекена и Охотника играется, против танков участников — попробуй на `0` (×0.5).

## Устройство

- `kit/arena/engine.js` — правила и физика, детерминированные и без DOM. Судья и песочница используют один и тот же код: результат раунда в браузере совпадает с `cli.mjs`.
- `kit/ARENA.md` — правила для участника, `kit/arena/cli.mjs` — песочница, `kit/arena/sparring/` — спарринг-боты «Охотник» и «Манекен».
- `viewer/` — просмотрщик. Каждый бот работает в отдельном Web Worker: он не может трогать движок, соперника или страницу. Ход дольше 50 мс пропускается (танк повторяет прошлую команду), примерно 3 секунды без ответа — бот отключается, матч продолжается.
- Карты симметричны относительно центра, стороны чередуются: каждая карта играется с обеих сторон. Зеркальный матч «Охотник против Охотника» даёт ровно поровну.

Проверка правил без браузера: `npm run sandbox`. Флаг `--fresh` у `cli.mjs` загружает обоих ботов заново перед каждым раундом: без памяти между раундами.

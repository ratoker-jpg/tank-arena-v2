# Танковая арена — правила для участника

Ты создаёшь танк для турнира один на один. Соперник — танк другого участника, его код тебе неизвестен. Бой показывают на видео: важен и результат, и то, как танк выглядит и ведёт себя.

Работай только внутри этой папки. Твой танк — папка `tank/`: при подведении итогов из этой папки берутся `bot.js`, `body.svg` и `turret.svg`, остальное организуй как хочешь. Папку `arena/` не меняй: судья использует свою копию движка, правки в твоей копии на бой не влияют.

## Что сдать

`tank/bot.js` — ES-модуль:

```js
export default {
  name: 'Имя танка',            // до 20 символов, покажется крупно на экране
  motto: 'Девиз',               // до 60 символов, для экрана представления
  stats: { armor: 3, engine: 3, gun: 2, reload: 2 },
  init(info) {},                // необязательно, в начале каждого раунда
  tick(state) { return { throttle: 0, turn: 0, turretTurn: 0, fire: false }; },
};
```

`tank/body.svg` и `tank/turret.svg` — внешний вид, вид сверху, `viewBox="0 0 64 64"`, носом вправо (+x). Точка (32, 32) — центр вращения корпуса и башни; башня рисуется поверх корпуса и вращается отдельно. На экране танк занимает 64×64 пикселя, тело столкновений — круг радиусом 24 вокруг центра. Цвета и стиль — твои.

Бот исполняется в браузере внутри Web Worker, а в песочнице — в Node. Нельзя использовать DOM, Node-модули, сеть и внешние пакеты. Можно импортировать свои файлы из `tank/` относительными путями и `../arena/engine.js`. Модуль загружается один раз на матч, поэтому состояние между раундами можно хранить в переменных модуля. Лимит на один `tick` — 50 мс; не успел — танк повторяет прошлую команду. Ошибка в `tick` — танк стоит этот ход.

## Характеристики

10 очков на четыре характеристики, каждая — целое от 0 до 5. Неверная раскладка — бот не допускается.

| Очки | armor: HP | engine: скорость, поворот | gun: урон, скорость снаряда | reload: перезарядка |
|---|---|---|---|---|
| формула | 100 + 25·armor | 110 + 22·engine px/с; 1.8 + 0.25·engine рад/с | 18 + 5·gun; 450 + 50·gun px/с | 1.3 − 0.16·reload с |
| 0 | 100 | 110; 1.80 | 18; 450 | 1.30 |
| 5 | 225 | 220; 3.05 | 43; 700 | 0.50 |

Башня у всех поворачивается со скоростью 2.8 рад/с. Разгон — 420 px/с², назад танк едет не быстрее 60% от максимальной скорости.

## Правила боя

- Поле 1600×900, x вправо, y вниз. Углы в радианах: 0 — вправо, π/2 — вниз (по часовой на экране).
- Симуляция идёт 30 тиков в секунду (`dt = 1/30`). Раунд длится до 120 секунд.
- Угол башни абсолютный: поворот корпуса её не крутит.
- Снаряд вылетает из точки в 34 px от центра по направлению башни. Если эта точка в стене, выстрел пропадает.
- Снаряд рикошетит от стены или края поля один раз, при следующем касании исчезает. Живёт 4 секунды. После рикошета может попасть и в своего стрелка.
- Снаряды, столкнувшиеся друг с другом, взаимно уничтожаются: вражеский снаряд можно сбить.
- Аптечки: появляются на 15-й секунде в двух симметричных точках, лечат на 50 HP (не выше максимума), после подбора возвращаются через 20 секунд.
- Зона: с 60-й по 100-ю секунду безопасный круг в центре сжимается до радиуса 170. Вне круга — 20 урона в секунду.
- Раунд выигрывает тот, кто уничтожил соперника. Если по истечении 120 секунд живы оба — побеждает тот, у кого выше доля оставшегося HP. Одновременная гибель или равенство — ничья.
- Четыре карты (Полигон, Лабиринт, Крепости, Каньон), все симметричны относительно центра. Карты идут по кругу, стороны меняются: каждая карта играется с обеих сторон. Бой — серия раундов до нескольких побед, затем длинная серия на скорости.

## Что видит бот

Каждый тик `tick(state)` получает полную информацию о поле, скрытого нет:

```js
{
  tick, time, timeLeft, dt, side,            // side: 0 — старт слева, 1 — справа
  arena: { width, height, mapName, walls: [{ x, y, w, h }] },
  me:    { x, y, heading, turret, speed, vx, vy, hp, maxHp, reloadLeft, alive, stats },
  enemy: { ...то же для соперника },
  bullets: [{ id, x, y, vx, vy, mine, bouncesLeft, damage, canHitOwner }],
  repairKits: [{ x, y, active, respawnIn }],
  zone: { x, y, radius, finalRadius, shrinkStart, shrinkEnd, damagePerSecond },
}
```

`stats` в `me` и `enemy` — уже пересчитанные величины: `maxHp, maxSpeed, turnRate, turretRate, damage, bulletSpeed, reloadTime`, а также исходные очки. `init(info)` получает `{ round, side, mapName, view }`, где `view` — такое же состояние на старте раунда.

## Команды

`tick` возвращает `{ throttle, turn, turretTurn, fire }`:

- `throttle` от −1 до 1 — газ вперёд/назад;
- `turn` от −1 до 1 — поворот корпуса (положительный — по часовой на экране);
- `turretTurn` от −1 до 1 — поворот башни;
- `fire` — выстрелить, если перезарядка закончилась.

Значения вне диапазона обрезаются, мусор считается нулём.

## Песочница

```
node arena/cli.mjs                     # tank/ против Охотника, 8 раундов: все карты с обеих сторон
node arena/cli.mjs --vs dummy          # против Манекена
node arena/cli.mjs --vs tank           # зеркальный матч против самого себя
node arena/cli.mjs --rounds 16 --map Каньон --verbose
```

Спарринг-боты лежат в `arena/sparring/`. Движок — `arena/engine.js`, это и есть точные правила; его можно читать и импортировать для собственных расчётов. Нужен Node.js 18+.
